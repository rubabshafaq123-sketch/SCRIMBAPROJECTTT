# Digital Business Card

A simple responsive digital business card built with HTML and CSS.

## Files

- `index.html` — the main webpage
- `styles.css` — page styling
- `images/profile.svg` — local profile illustration

## Run locally

Open `index.html` in your browser.

## Deploy with Netlify

Upload this whole project folder to Netlify Drop, or connect the GitHub repository to Netlify.

Make sure `index.html` remains in the project root.
